# benlink-product 项目说明

本来生活（Benlai）分销定价项目。核心资产是**两个货盘的定价交付物**、采集与校验脚本、源数据快照和业务口径文档。私有仓库，含敏感价格数据（成本/供货价/协议价）。

## 这个项目在做什么

一句话：**给本来生活的分销商品自动定价，同时把技术公司能卖的完整供应链（三个货源）整合成一张可经营的聚合货盘。**

### 两个货盘（业务顶层框架，不可混）

```
货盘一 = 本来货盘（本来定制）
  本来分销底盘（四站可售 + 选品规则）
    → ERP成本 × 分档加价（直发 2/5/8%、仓发 5/12/24%）
    → 市场价参照：天镜智价（主）+ 京东VOP相似采信 + 猫超券后价折算（补）
  服务对象：只供本来生活体系。周频滚动更新。

货盘二 = 技术公司全货盘（自营生意）
  货盘一原样搬入（本网=内部产出，保留内部逻辑）
  + 京东VOP（外部引入，协议价=进货成本，直发档 2/5/8%）
  + 猫超（外部引入，SKU供货价=进货成本，直发档 2/5/8%）
  三表并集、每货源一行、同品组 group_id 关联、空间率≥10% 过滤。
```

关键认知：猫超和京东 VOP 在两个货盘里**角色不同**——对货盘一是"定价的镜子"（市场价参照），对货盘二是"货源"（进货成本）。

## 文件夹结构

### 交付物/ —— 唯一对外出口，按周归档（最重要）

```
交付物/
├── 2026-W46/  底稿数据（早期ERP成本、京东比价老表）
├── 2026-W47/
│   ├── 01_货盘一_本来定制/    禄品4940定价、标准池定价11-19、同品关系主表
│   ├── 02_货盘二_技术公司全货盘/  全货盘聚合表csv + 链路说明HTML
│   └── 03_底稿数据/           本网池、京东VOP底表、猫超四件套、天镜数据、取数说明
└── 2026-W48/  （同上结构，最新一周：选品v2 + 聚合表修正版）
```

**为什么放这里**：所有最终产出只从周文件夹对外交付；每周一份"底稿+两货盘成品"，周频更新可回溯、可对账。历史周不删（git 保留），底稿保证任何一周的结论都能复算。
规则：周文件夹只用 ISO 周号命名；周内经确认的归档命名不要日期区间。

### pricing_output/ —— 货盘一工作区（脚本 + 中间产物）

定价标准池的采集、匹配、定价、报告脚本（pull_erp_site_costs、match_pool_vop、build_standard_pool_pricing、build_chain_report 等），以及中间产物（含新京东价、候选相似度等早期版本）。

**为什么与交付物分开**：这里是"厨房"，交付物/是"上桌的菜"。脚本留原处可复跑；成品产出后移入交付物对应周文件夹，避免一处多份。

### allpool_output/ —— 货盘二工作区（聚合表流水线脚本）

全货盘的 8 个脚本：条码提取与对齐（pull_bl_barcodes、match_barcodes、match_bl_maochao）、选品重筛（rescreen_pool）、任务1猫超折算补价（task1_maochao_price）、京东↔本网/猫超匹配（match_jd_allpool）、聚合表组装（build_allpool）。中间对齐 jsonl 已随周归档移入交付物。

### jdvop_pull/ —— 外部货源采集区（京东VOP + 猫超TOP接口）

- `jdvop_pull.py` 系列：京东 VOP 商品池拉取（含能力包交接说明）
- `maochao_*.py` 系列：猫超阿里 TOP 三接口直连（list scroll 全量遍历 / detail 详情 / price 供货价+券后价），含断点续跑与看门狗
- `output/`：采集原始落盘（大文件，部分已归档进交付物）；`credentials.json` 等凭证**不入库**

**为什么独立**：外部接口采集自成一条线，与定价计算解耦——采回来的底表先进交付物归档，定价脚本再消费。

### 00_项目汇总/ —— 业务台账（95012 业务线）

交付汇总.md（完整历史与口径）、交付文件清单.csv（R6：新交付物按路径 upsert 登记）、新电脑接手指引.md。

### 01_源数据 ~ 06_校验记录 —— 95012 禄品业务线

10 月底-11 月中旬的 95012 报价业务：源数据、报价表各版本、入盘建议、履约成本试算、处理脚本与 QA（05_数据与脚本/，166 个文件）、校验记录。口径见 `AGENTS.md` 第 2 节（生鲜5类末次采购成本、其余渠道中位数加权）。

### 其他

- `.ai/`：状态机（state.md）、决策记录（decisions/）、verify.py 环境验证
- `AGENTS.md`：工作规则与权威业务口径（改口径先看这里）
- `本来生活VOP_goods.csv`：京东VOP原始价格表（18M，定价源头之一）

## 每周更新流程（周频节奏）

1. 采：天镜智价最新价库 + 猫超/京东外部价刷新 → 新底稿
2. 筛：四站全上架 + 有库存 + 选品规则（含冷链/常温剔除）→ 新池
3. 算：货盘一定价（成本口径+三档+建议档）→ 货盘二聚合（三货源并集+空间率）
4. 存：全部进 `交付物/2026-Wxx/`，登记清单，提交推送

## 环境与复跑

- Python venv：`~/ai-workspace/local/venv`（openpyxl、beautifulsoup4）
- 生产库只读：Archery 能力包（`~/ai-workspace/shared/benlai-trace-debug`，软链，凭证不入库）
- 大文件走 Git LFS：克隆后必须 `git lfs pull`
- 验证：`python3 .ai/verify.py`
- 脚本均支持环境变量覆盖路径（R1 自包含），按周重跑传新日期/新路径即可
