两大货盘 · 全流程链路（定稿）

2026-11-23 · 框架经用户三次确认定稿 · 核心：外部渠道对货盘一是"定价的镜子"，对货盘二是"货源"
一句话记住：本来分销底盘（ERP 商品池）靠 天镜智价 + 猫超券后价 这些市场价参照完成定价，产出本来货盘（货盘一）；本来货盘 + 猫超 + 京东VOP 三个货源并成 本来技术公司货盘（货盘二）。
货盘一 74,980 品（2026-11-23 选品v2） 货盘二 322,503 行（2026-11-23 v2） 成本口径 ERP / 猫超供货价 / 京东协议价 空间底线 ≥10% 全程只读 · 凭证零入库 · GitHub 私有
货盘一 = 本来货盘 = 本来分销底盘 × 定价（ERP成本×分档 + 市场价参照）
底盘：四站全上架+有库存+选品规则（冷链/常温低价剔除）；参照：天镜为主、猫超券后折算、京东VOP 相似采信
货盘二 = 技术公司货盘 = 本来货盘 ＋ 猫超货源 ＋ 京东VOP货源
本来=内部产出原样搬入（内部加价档）；猫超/京东=纯外部引入（对方发货→直发档 2/5/8）
同一个渠道，两个角色 —— 这就是"内部产出 vs 外部引入"的分界
