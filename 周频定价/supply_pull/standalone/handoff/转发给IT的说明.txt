【请帮个小忙：借一台"从指定 IP 上网"的机器】

一句话背景
我们有一套京东开放平台账号，京东那边只允许从下面 5 个公司 IP 调用接口，
这 5 个 IP 是固定的、京东后台现在不能再加新 IP。
我目前这台电脑的上网出口是 180.167.74.98，不在名单里，所以京东直接拒绝，
商品数据一条都拉不到。这不是程序问题，也不是密钥问题，纯粹是"从哪个 IP 出去"的问题。

★ 已放行的 5 个 IP
39.102.184.125
39.102.184.126
39.102.184.127
39.102.184.96
8.153.82.69

★ 想要什么
一台"上网出口是上面 5 个 IP 之一"的机器，能 SSH 登录就够了。

线索（帮你们快速定位）：
1) 线上应用配置里 white-ip 写的就是 39.102.184.127，
   说明同一套阿里云环境里的开发机 / 测试机 / 跳板机最可能符合；
2) 运维文档里也写了"线上库在阿里云 VPC 内网，本机直连不通，需要同 VPC 跳板机"。
   也就是说这类机器本来就有，只是地址在你们手里。
3) 已核实这 5 个 IP 全是【阿里云 ECS 的公网地址】（4 个北京、1 个上海），
   不是公司办公网的出口。所以要找的是阿里云上的机器，
   不是办公室局域网里的电脑；连公司 VPN / 办公室 Wi-Fi 大概率不匹配，别优先试。

不用生产应用服务器；不用装任何软件；不用改任何配置；
密码 / 密钥在你们自己手里，不用交给我，通道由我们自己在本机开。

★ 回我一句就行，两种都可以
A. 给一个能 SSH 登录的地址（用户名@机器地址，端口不是 22 请注明）。
   我们自己在电脑上开一条只供本机使用的通道，数据全程留在我们这台电脑，
   你们机器上不留文件、不留进程、不留账号。
B. 不方便给登录方式的话：在那台机器上跑一下随附的 check_from_server.py，
   把屏幕上最后那行"结论"发回即可。
   这个脚本不含任何账号密钥，只用 Python 自带功能，不写文件、不上传数据。
   确认出口命中之后，再麻烦帮忙开一条临时通道，
   或者直接帮忙把拉取结果文件发回（脚本我们另外给，同样不含密钥）。

★ 最简版：连脚本都不用放，在网页终端里粘一条命令
   curl -s https://ifconfig.me ; echo
   把显示出来的 IP 发回即可，是上面 5 个之一就说明这台机器可用。
   阿里云 ECS 的 Workbench 网页终端可以直接粘，不需要 SSH 地址。

★ 如果你们能登阿里云控制台（最省事）
   ECS 实例列表里找「公网 IP 是上面 5 个之一」的那台实例，
   那个公网 IP 就是「机器地址」（用户名一般是 root 或 ecs-user），
   抄下来发我即可；不方便开 SSH 的话，用网页终端跑上面那条命令也行。

★ 几点说明（免得误会）
- 不是要绕开安全限制：用的是公司自己早就放行的 IP，京东后台一个配置都不用改。
- 全程只读：只调京东的商品查询接口，不写数据库、不发消息、不改线上任何东西。
- 不用给任何账号密钥：随附的两个检查文件都不含凭证，运行时也不需要输入。
- 这台机器如果出口不是上面 5 个之一，回一句"不匹配"就行，我们再换思路，不用你们继续折腾。

谢谢！
